Data Deletion Instructions

Last updated: April 23, 2026

How to Delete Your Data

The Halk Kompleksi application stores all data locally on your device. No data is stored on external servers. To delete all your data, follow these steps:

  1. Revoke Facebook Permissions: Go to your Facebook Settings → Apps and Websites → Find "Halk Kompleksi" → Click "Remove"
  2. Delete Local Data: Remove the application folder and all associated files from your device, including:
    • The .env file containing access tokens
    • The facebook_session/ folder containing browser session data
    • The downloads/ folder containing cached images
    • The seen_hashes.json file containing processing records
  3. Clear Browser Data: If you used the application's browser automation, clear the browser profile data stored in the facebook_session directory.

Note: Since all data is stored locally on your device, once you delete the application files, all associated data is permanently removed. We do not retain any copies.
